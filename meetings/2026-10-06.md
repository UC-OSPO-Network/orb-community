# ORB Community Call: 6 October 2026

**Attendees:** Juanita Gomez, Virginia Scarlett, Emily Lovell, Laura Langdon

Our first monthly community call. We agreed to publish a short written summary after each call (no recordings), kept here in `orb-community`.

## Priorities (Juanita)

1. Move repofinder's scraping from GitHub's REST API to GraphQL, for much faster scraping. Some open PRs already start this.
2. Move classification off OpenAI, since our credits have run out.
3. Add more sustainability metrics to the dashboard: issue and PR response times, engagement, commit activity.
4. Decide on data storage and set it up.

1 and 2 don't depend on the storage decision. We'll check with the developer team working on ORB before anyone starts on them, so work isn't duplicated.

## Decisions

- **Notes:** written summaries, no video; AI-assisted notes are fine. They live in this repo.
- **Classification, short term:** we'll try to get Anthropic API credits. Running local models is the longer-term goal.
- **Compute:** cloud rather than self-managed hardware, if credits come through.

## Direction on data (not final)

We have three data sets: the raw scrape (which includes contributor details), the dashboard's Parquet files, and the Showcase data. The direction is a private S3 bucket for the raw data, with a few admins, and Zenodo downstream for public downloads and data-use-agreement requests. Next steps are sizing the storage (raw ~100 GB, Parquet ~1 GB) and asking about AWS credits.
