# ORB community call summaries

The ORB community call meets on the first Tuesday of each month, 1–2pm Pacific, and is open to anyone. Joining details are on the [UC OSPO Network events page](https://ucospo.net/events/#orb-community-call).

Calls aren't recorded. After each call we publish a short AI-assisted summary here.
